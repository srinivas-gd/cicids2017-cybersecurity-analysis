# CICIDS2017 Cybersecurity Analysis

## Overview
This project focuses on cybersecurity attack detection and network traffic analysis using the CICIDS2017 dataset. The project demonstrates various data preprocessing and machine learning preprocessing techniques on large-scale real-world cybersecurity data containing DDoS attack traffic and benign network traffic.

The analysis includes:
- Data preprocessing
- Missing value handling
- Outlier detection
- Data visualization
- Correlation analysis
- Principal Component Analysis (PCA)
- Feature engineering
- Feature selection

The project aims to identify important network traffic patterns and improve understanding of cybersecurity intrusion detection systems.
